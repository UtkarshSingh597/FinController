# Database and migrations

FINCONTROL uses PostgreSQL through SQLAlchemy 2.x and the Psycopg 3 driver. The production database URL is supplied through `FINCONTROL_DATABASE_URL`; do not place production credentials in source control.

Run migrations from `backend/`:

```powershell
.\.venv\Scripts\alembic.exe upgrade head
```

Create a reviewed migration after modifying SQLAlchemy domain models:

```powershell
.\.venv\Scripts\alembic.exe revision --autogenerate -m "describe change"
```

Autogenerated revisions are never a substitute for review. In particular, confirm indexes, foreign keys, tenant constraints, enum changes, and downgrade behavior before applying a revision.

The initial baseline contains no tables by design. The first schema migration belongs to Phase 5, when the financial domain is introduced.
